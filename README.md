# GitHub Pages Support Site

This folder contains the public support site for `Your Smart Listening (Pro)`.

## Files

- `index.html`: support landing page
- `privacy.html`: privacy policy page
- `styles.css`: shared site styles
- `favicon.svg`: lightweight site icon

## Before Publishing

1. Replace every `support@yourdomain.com` placeholder with your real support email.
2. If the app is already live, replace the "App Store listing: available after release" text in `index.html` with the real App Store URL.
3. Review the privacy policy wording and confirm it matches the app's final shipping behavior.

## Publish With GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open `Settings > Pages`.
3. Set the build source to `Deploy from a branch`.
4. Choose your main branch and the `/docs` folder.
5. Save and wait for GitHub Pages to publish.

Your public URLs will look like:

- Support URL: `https://zaparzeez-wq.github.io/<repo>/`
- Privacy Policy URL: `https://zaparzeez-wq.github.io/<repo>/privacy.html`

## App Store Connect

Use the published GitHub Pages URLs in these fields:

- `Support URL` -> site root
- `Privacy Policy URL` -> `privacy.html`
